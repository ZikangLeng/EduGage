# eSense IMU Collection

`eSense_connect.ipynb` records eSense earable IMU samples over BLE and writes an
IMU CSV.

Install the notebook dependencies with:

```bash
python -m pip install -r Data_Collection/eSense/requirements.txt
```

Before running the notebook, replace the placeholder `ESENSE_MAC_ADDRESS` value
with the local eSense device identifier for the collection machine.
